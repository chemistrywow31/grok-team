# Task board

> 指引：每個主管一張，由該主管自己更新。複製到該專案放進度的地方。範例列用完就刪。變動的列用八行回報往上送，不把整張板貼出去。

`status` 只使用：`IN_PROGRESS`、`DONE`、`DONE_WITH_CONCERNS`、`BLOCKED`、`NEEDS_CONTEXT`。

| task | status | blocker reason | needs human decision | output | start | end |
| --- | --- | --- | --- | --- | --- | --- |
| （範例，刪掉）確認範圍 | IN_PROGRESS | none | no | none | YYYY-MM-DD | |

- blocker reason 沒有就寫 `none`
- needs human decision 只寫 `yes` 或 `no`
- output 要是使用者打得開的東西。還沒有就 `none`
- `DONE` 和 `DONE_WITH_CONCERNS` 要填 end
- `BLOCKED`、`NEEDS_CONTEXT` 要寫 blocker reason，end 留空

欄位說明見 [../docs/operating-rules.md](../docs/operating-rules.md)。
