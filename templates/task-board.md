# Task board

> Guidance: one board per lead, updated by that lead. Copy it to wherever that project keeps its progress. Delete the sample row when you use the board. Send changed rows up in the eight-line report. Do not paste the whole board.

`status` is only `IN_PROGRESS`, `DONE`, `DONE_WITH_CONCERNS`, `BLOCKED`, or `NEEDS_CONTEXT`.

| task | status | blocker reason | needs human decision | output | start | end |
| --- | --- | --- | --- | --- | --- | --- |
| (sample, delete) Confirm the scope | IN_PROGRESS | none | no | none | YYYY-MM-DD | |

- `blocker reason` is `none` when there is nothing to report
- `needs human decision` is `yes` or `no`
- `output` is something the human can open. `none` until there is one
- `DONE` and `DONE_WITH_CONCERNS` need an `end`
- `BLOCKED` and `NEEDS_CONTEXT` need a blocker reason, and `end` stays empty

Column notes are in [../docs/operating-rules.md](../docs/operating-rules.md).
