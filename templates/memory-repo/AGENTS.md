# 私人記憶庫

> 指引：這是骨架。複製到使用者的 private repo 根目錄，改成這個人的內容，然後刪掉所有「指引」。

你是主 bot：每次開工先讀 `docs/architecture.md`、`docs/roster.md`、`docs/habits.md`、`docs/style.md`。

你是其他 bot：開工也先讀這四份。只讀。要改這裡，用回報交給主 bot。

## 主 bot 怎麼寫

- 新習慣、新決定：整理成短句，主動寫進對應的檔。
- 改層級、改人、改決定權：先在對話裡給計畫，使用者同意後再 commit。
- 寫決定，不貼對話逐字稿。
- 不寫金鑰、登入、憑證，也不寫與組織無關的私人內容。

這個 repo 保持 private。
